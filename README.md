# ToDo List

Веб-приложение для планирования задач, разработанное в рамках второй лабораторной работы по веб-программированию на чистом JavaScript, HTML и CSS. Весь интерфейс создаётся динамически через DOM API, без использования фреймворков.

Можно добавлять, редактировать и удалять задачи, отмечать их выполнение, искать по названию, фильтровать по статусу и сортировать по дате. В режиме «вручную» порядок задач меняется перетаскиванием. Задачи сохраняются в localStorage и восстанавливаются при следующем открытии страницы.
